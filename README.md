# DevOps Capstone Project
 
[![CI Build](https://github.com/jonathan777888/devops-capstone-project/actions/workflows/ci-build.yaml/badge.svg)](https://github.com/jonathan777888/devops-capstone-project/actions/workflows/ci-build.yaml)
 
This repository contains the DevOps Capstone Project for the Customer Accounts microservice.
 
The project includes:
- User stories and sprint planning
- RESTful API implementation
- Automated testing
- Continuous Integration with GitHub Actions
- Security headers and CORS
- Docker containerization
- Kubernetes deployment
- Continuous Deployment with Tekton
